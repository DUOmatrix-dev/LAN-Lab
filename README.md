LAN Network Lab

An interactive educational platform designed to help students understand Local Area Networks (LANs), network characteristics, topologies, Ethernet technologies, switching and wireless networking through visual demonstrations and practical simulations.

Features

1. LAN Fundamentals
- Introduction to Local Area Networks.
- Characteristics of LANs.
- Network devices and their functions.
- LAN and WAN comparisons.

2. Network Topologies
- Bus topology.
- Star topology.
- Ring topology.
- Mesh topology.
- Interactive network diagrams.
- Advantages and disadvantages of each topology.

3. Access Methods and Ethernet
- MAC addressing.
- CSMA/CD and CSMA/CA.
- Ethernet technologies.
- Data transmission concepts.

4. Switching and VLANs
- Ethernet switching.
- MAC address learning and forwarding.
- VLAN configuration concepts.
- Access and trunk ports.
- IEEE 802.1Q tagging.

5. Spanning Tree Protocol (STP)
- Understanding Layer 2 loops.
- Root bridge selection.
- Port roles and states.
- Interactive STP simulations.

6. Wireless LANs
- Wireless networking concepts.
- Access points.
- Wi-Fi frequency bands.
- Signal strength and roaming simulations.

7. Practical Networking Lab
- Interactive Cisco-style switch CLI.
- VLAN creation and configuration.
- Access port configuration.
- Trunk port configuration.
- Switch configuration commands.
- Practical networking exercises.

8. Learning and Assessment
- Interactive quizzes.
- Flashcards.
- Knowledge checks.
- Networking glossary.
- Recommended learning resources.
- Learning progress tracking.

Technology Stack

- React 19 – User interface development.
- TypeScript – Type-safe application development.
- Vite – Development server and build tool.
- Tailwind CSS 4 – Styling and responsive interface.
- SVG – Interactive network diagrams and animations.
- Local Storage – Saving learning progress locally.

Getting Started

Prerequisites

Make sure you have installed:

- Node.js
- npm

 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/lan-network-lab.git
   ```

2. Navigate into the project directory:

   ```bash
   cd lan-network-lab
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

Production Build

To generate an optimized production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

Project Purpose

LAN Network Lab aims to make computer networking easier to understand through interactive learning, visual explanations and practical simulations.

It is particularly useful for networking students, beginners, instructors and anyone interested in understanding how Local Area Networks operate.
